# 术语对照（社区习惯用语）

来源：Ballance Wiki（ballance.jxpxxzj.cn，「机关」条目及其元素列表）。
与用户沟通和写中文文档时按本表用词；英文文档保留内部名（`P_Modul_XX`
等）。

## 关卡结构

| 内部名 / 英文 | 社区用语 | 说明 |
|---|---|---|
| sector | 小节 | 不说"扇区" |
| checkpoint (PC_TwoFlames, Sector_*) | 存档点 | 激活下一小节；粉色双火焰 |
| resetpoint (PR_Resetpoint) | 重生点 | 球死亡后在当前小节的重生点复活 |
| level end, PE_Levelende, balloon / airship (PE_Balloon) | 飞船（飞碟） | 过关处；本项目中为例外，不进共享物理状态 |
| death zone (DepthCubes) | 死亡区 | |
| level | 关卡、第 N 关 | |
| spawn / respawn | 出生、重生 | |
| lives / score | 生命、分数 | |

## 球

| 内部名 | 社区用语 |
|---|---|
| Ball_Wood / Ball_Stone / Ball_Paper（玩家球） | 木球 / 石球 / 纸球 |
| P_Ball_Wood / P_Ball_Stone / P_Ball_Paper | 道具木球 / 道具石球 / 道具纸球（统称道具球） |
| trafo, transformation | 变球（不说"变形"） |
| P_Trafo_Stone / Wood / Paper | 石球变球器 / 木球变球器 / 纸球变球器（变球器，又称转换器） |
| explosion pieces (Ball_*Pieces) | 变球后的碎片、碎片 |
| P_Extra_Life | 生命球 |
| P_Extra_Point | 分数球（不说"加分点"） |

元素分类（Wiki）：自由移动（活式木栅栏、道具球、箱子）；单轴旋转（秋千、
单摆、双向挡板、推板、跷跷板、T 型板、箱式浮板）；单轴位移（升降机、落石）；
效果辅助（风扇、变球器、生命球、分数球）；单点悬挂（沙袋）；固定（软木桥、
Dome）。道路：路面、木板、钢轨、Stopper、FixCube。
